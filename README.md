# C¹ — CustomerFirst

**One individual. One work. One moment of value.**

This repository contains the website of *CustomerFirst*, an ongoing art project:
each work is created for one specifically chosen individual. Only that person may
acquire the work — and determines its value, or decides not to. Every outcome is
part of the work.

The site is a single, self-contained page: `index.html` holds all text, styling,
images and the status tracker. There is no build step and there are no dependencies.

- **Live site:** https://cfirstproject.github.io
- **Instagram:** [@cfirstproject](https://www.instagram.com/cfirstproject)
